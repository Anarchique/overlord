Code d'honneur

Les Règles

Cliquez sur une règle pour afficher le détail. Les respecter, c'est respecter la faction.

Aucune insulte, discrimination ou harcèlement, sur Discord comme en jeu. Les désaccords se règlent en privé avec un officier.
Sanction : avertissement → mute → bannissement

Pas de double appartenance à une faction rivale. Trahison, fuite d'informations ou espionnage entraînent une exclusion immédiate.
Sanction : exclusion définitive

Hacked clients, x-ray, duplication et bugs exploités sont interdits. Nous gagnons par le skill et la stratégie.
Sanction : bannissement

Pendant une opération, le chef de raid décide. Pas de loot solo, pas d'initiative non coordonnée.
Sanction : retrait de rang

Préviens en cas d'absence de plus de 14 jours dans #absences. Les membres inactifs sans justification sont retirés.
Sanction : rétrogradation

Utilise les bons salons, évite les mentions abusives et ne fais pas de pub pour d'autres serveurs ou communautés.
Sanction : mute → bannissement
